ForgeLoop is an evidence-first engineering protocol for AI coding agents and
developer workflows. It moves each task through a validated lifecycle: contract,
routing, execution, verification, review and a validator-backed completion. The
ForgeLoop CLI stays the authority for state, gates, evidence and completion.

  repository's `docs/` folder. The normative protocol documents live at the
  repository root on [GitHub](https://github.com/cassiomc1/forgeloop).
</Info>

## Install

```bash
npm install --global @cassiomc1/forgeloop
forgeloop init
forgeloop doctor
```

Requires Node 24.19.0+ with `node:sqlite`.
